# Weekly digest for open-source Kortix

Use this skill when a session on open-source Kortix asks for the weekly digest.

1. Read the commits and the change requests updated since the last digest.
2. Group the work by the outcome it delivered.
3. List the risks and the blockers that are still open.
4. Write one page, then open a change request with it.

The report uses this shape:

| Outcome | Work | Status |
| --- | --- | --- |
| Faster checkout | Three commits, one change request | Merged |
| Clearer onboarding | Two commits | In review |

Keep each row to one line. Link a change request when the reviewer needs the detail.
